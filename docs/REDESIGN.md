# Reel — UI/UX 고도화 기획서

> 목표: macOS 최신 HIG 준수, 불필요한 요소 제거, minimal but complete

---

## 1. 분석: 현재 Reel의 문제점

### 1.1 메인 윈도우(`MainWindowView`) — 정보가 과포화됨

| 영역 | 현재 상태 | 문제 |
|------|----------|------|
| 사이드바 | 7개 필터(inProgress/queued/completed/failed/all/audio/stats) | 각각 다른 빈 상태 문구, 공간 낭비 |
| 툴바 | URL 입력 + 프리셋 + 플레이리스트 모드 + 진행률 표시 | 4개 요소가 가로로 늘어남 |
| 상태바 | 진행 중/대기/완료/동시성 — 4개 정보 | 항상 보이는데 실제 액션 연결 없음 |
| 채널 미리보기 | 드래그 시 카드 오버레이 | 이례적 케이스를 기본 화면에 띄움 |

**핵심 문제**: 1초만에 "무엇을 해야 할지" 알 수 있어야 하는 다운로드 앱에 정보가 너무 많습니다.

### 1.2 메뉴바 뷰(`MenuBarView`) — 항목이 너무 많음

- 대기 중인 항목 1개당 진행률 바 + 제목 + 취소 버튼이 모두 표시됨
- 5개 이상 큐에 쌓이면 menu가 너무 길어짐
- "추가 링크" 버튼이 항목 목록 사이에 섞여 있음

### 1.3 설정 화면(`SettingsView`) — 옵션이 산만함

- 기본 설정, 고급 설정, 부가 옵션, 플레이리스트, 정리, 업데이트 — 6개 탭
- 부가 옵션 중 자주 쓰는 것(enChapters, embedMetadata)과 안 쓰는 것(enThumbnail)이 섞여 있음
- SponsorBlock, 자막, 자막언어, 브라우저 쿠키가 별도의 섹션으로 분리됨

### 1.4 통계 뷰(`StatisticsView`) — 메뉴바와 메인 윈도우 양쪽에서 중복 노출

- 사이드바 → 필터 "통계" → StatisticsView
- 메인 윈도우 툴바 → 완료 지우기 버튼
- 둘 다 같은 목적인데 경로는 서로 다름

## 2. 벤치마크: 경쟁 제품들의 접근 방식

| 앱 | 핵심 철학 | 구조 |
|----|----------|------|
| **Downie** | "드래그하면 바로 다운로드" | 단일 카드 + 옵션 disclosure |
| **Slidown** | "paste → button → done" | 입력 + 버튼 1개, 큐는 별도 |
| **Pulltube** | "간결함 우선" | URL 입력 → 메타데이터 → 프리셋 선택 → 다운로드 |
| **macYT** | "native Mac app 느낌" | 시스템 컴포넌트만 사용, 커스텀 요소 최소화 |
| **YT-DLP-GUI** | "progressive disclosure" | 기본 경로 단순, 고급 옵션은 collapse |

**공통점**: 핵심 워크플로우(paste URL → download)를 1~2초 내에 완료할 수 있음. 옵션은 필요한 순간만 노출.

## 3. 제안: 리팩토링 방향

### 3.1 메인 윈도우 — 사이드바 제거, 탭+리스트 단순화

```
┌──────────────────────────────────────────────────────┐
│  Reel                                    [─][□][×] │
├──────────────────────────────────────────────────────┤
│  [링크 붙여넣기 또는 드래그]         [프리셋 ▼] [+] │
├──────────────────────────────────────────────────────┤
│  진행 중 (2)                                          │
│  ┌─────────────────────────────────────────────────┐ │
│  │ [썸네일] 제목                                    │ │
│  │          ████████░░ 45% · 3.2 MB/s · 2분        │ │
│  └─────────────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────────────┐ │
│  │ [썸네일] 제목                                    │ │
│  │          ██████████ 78% · 5.1 MB/s · 45초       │ │
│  └─────────────────────────────────────────────────┘ │
│                                                       │
│  대기 (3)                                             │
│  ┌─────────────────────────────────────────────────┐ │
│  │ [썸네일] 제목                                    │ │
│  │          대기 중 3위                              │ │
│  └─────────────────────────────────────────────────┘ │
│  ...                                                 │
├──────────────────────────────────────────────────────┤
│  동시 3개 | 3분 | 128MB/s                            │
└──────────────────────────────────────────────────────┘
```

**변경 사항**:
- ❌ 사이드바 7개 필터 → ✅ **탭 2개**(진행 중/완료) + "전체" 자동 감지
- ❌ 툴바 4개 요소 → ✅ **입력줄 + 프리셋 + 추가 버튼** 3개만
- ❌ 4개 영역의 상태바 → ✅ **간결한 하단 바**(동시성만)
- ✅ 완료 항목은 완료 탭에서 확인, 진행 중 항목은 진행 중 탭
- ✅ 하단 바에 "완료 N개" 클릭 시 완료 탭으로 이동

### 3.2 메뉴바 뷰 — 핵심 상태만, 압축 표시

```
┌─────────────────────────────┐
│  ↓ 72%   [추가 링크 +]      │  ← 활성 다운로드 진행률 + 추가 버튼
├─────────────────────────────┤
│  ▶ 영상 제목 (진행 중)       │  ← 진행 중 1개만 표시 (진행률 생략)
├─────────────────────────────┤
│  [완료 3개]                  │  ← 완료 항목 수 (클릭 시 메인 윈도우)
├─────────────────────────────┤
│  설정                        │
│  yt-dlp 정보                 │
│  Reel 정보…                  │
│  업데이트 확인…              │
│  ──────────────────────────  │
│  종료                         │
└─────────────────────────────┘
```

**변경 사항**:
- ❌ 큐 항목 전체 목록 → ✅ **진행 중 1개만** (그것도 제목만, 진행률 x)
- ❌ 각 항목별 취소 버튼 → ✅ **메인 윈도우에서 관리**
- ✅ 완료 항목은 "완료 N개" 버튼으로 요약
- ✅ 메뉴바에서 직접 다운로드 추가 가능 (클립보드 URL 감지)

### 3.3 설정 화면 — 6탭 → 3탭으로 단순화

```
설정
├── 일반 (2개 탭)
│   ├── 다운로드
│   │   ├── 기본 프리셋
│   │   ├── 출력 폴더
│   │   ├── 동시 다운로드 수
│   │   └── 저전력 프로필
│   └── 알림
│       ├── 완료 시 알림
│       └── 클립보드 자동 감지
├── 고급 (2개 탭)
│   ├── 처리 옵션
│   │   ├── 자막 임베드 (토글)
│   │   ├── 챕터 임베드 (토글)
│   │   ├── 메타데이터 임베드 (토글)
│   │   └── SponsorBlock (토글)
│   └── yt-dlp
│       ├── 버전 표시
│       └── 업데이트 버튼
└── 정리 (1개 탭)
    ├── 완료 항목 자동 정리 (토글)
    └── 정리 주기 (3/7/14/30일)
```

**변경 사항**:
- ❌ 6개 탭 → ✅ **3개 탭**(일반/고급/정리)
- ❌ 부가 옵션 분리 → ✅ **처리 옵션** 한 곳에 모음
- ❌ 플레이리스트 별도 → ✅ **일반** 탭으로 이동
- ❌ 통계 화면 → ✅ **메인 윈도우 탭**으로 통합

### 3.4 통계 — 메인 윈도우 내 탭으로 통합

- 메인 윈도우 하단에 통계 요약 표시 (완료 수, 총 용량, 이번 달)
- "통계 보기" 링크 클릭 시 메인 윈도우 내에서 expands
- 메뉴바에서 통계 접근 제거 (메인 윈도우 탭으로 통합)

## 4. UX 원칙

1. **One second rule** — 앱 열면 "뭔가 붙여넣으라"는 것이 1초 안에 이해되어야 함
2. **Progressive disclosure** — 기본 기능은 무조건 보임, 고급 기능은 disclosure triangle
3. **OS-native** — 시스템 컴포넌트(List, Picker, Toggle, Button)만 사용
4. **상태는 하나만** — 진행 중 / 완료 / 대기, 하나의 탭에 하나의 상태
5. **메뉴바는 상태만** — 메뉴바에서 완전한 작업 흐름이 아니어야 함
