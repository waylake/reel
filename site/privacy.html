Privacy

Nothing leaves your Mac unless you ask it to.

Last updated 10 November 2026. This policy covers the Reel app and this website, and it is short on purpose.

The app What it stores Network calls This website Contact

The app

Reel has no analytics, no telemetry, no crash reporting, no advertising and no user accounts. There is no Reel server: we cannot see your downloads, your links or your cookies, because nothing is sent to us.

What it stores on your Mac

  • Queue — ~/Library/Application Support/Reel/queue.json. Titles, URLs, progress and output paths.
  • Settings — macOS UserDefaults, under com.waylake.reel.
  • Updated engine — ~/Library/Application Support/Reel/bin/, if you update yt-dlp from the app.
  • Clipboard — read in memory to detect media links. The text is never written to disk and never transmitted. Detection can be turned off in Settings.

Network calls

Two, and only two:

  1. The media site. yt-dlp connects directly from your Mac to the site you gave it. If you enabled login cookies, they are handed to yt-dlp for that request and go to that site only.
  2. The update check. Sparkle fetches a signed appcast from GitHub Releases. It sends no identifier, and you can disable automatic checks in Settings.

There is no other outbound traffic from the app: no pings, no feature flags, no remote configuration.

This website

reel.waylake.com is static files. It sets no cookies, runs no analytics, loads no third-party fonts, scripts or images, and embeds nothing. The only JavaScript reads the latest release tag and size from GitHub's public API so the version on this page is current; that request goes from your browser to GitHub, not to us. GitHub may log it under GitHub's privacy statement.

Contact
