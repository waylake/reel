Changelog

Every version, in order.

Reel ships often because yt-dlp ships often. Releases are tagged on GitHub; existing installs update through Sparkle. The full diff for each release is one click away.

1.3.2 1.3.1 1.3.0 1.2.0 1.1.1 1.1.0 1.0.0 All releases →

1.3.2 2026-11-07

  • Fixed ⌘V adding nothing when the clipboard held a link.
  • Removed click-to-add. A link is added with ⌘V or by dropping it on the window — one gesture, no accidental imports.
  • README and this site rewritten around the ⌘V workflow.

1.3.1 2026-11-07

  • Fixed the main window collapsing to a 32-point-wide strip when SwiftUI reported its ideal size before AppKit laid it out.

1.3.0 2026-11-07

  • Downloads are thumbnail cards with live progress, speed and time remaining.
  • Translucent window background; settings regrouped into General, Downloads and Advanced.
  • English README, contribution guide, security policy, issue and pull request templates, and new screenshots.

1.2.0 2026-11-06

  • Clipboard-first interface: the URL field, format dialog and multi-tab toolbar are gone.
  • Cookie extraction falls back to a signed-out download instead of failing the item.

1.1.1 2026-08-22

  • YouTube bot-detection errors are retried, and yt-dlp updates itself when a run fails.
  • Extraction stage is shown while a download is being resolved.
  • Test infrastructure: 57 tests, a smoke-test script, and crash-log analysis without triggering permission prompts.

1.1.0 2026-08-22

  • Channel preview before queueing.
  • Fixed stalls on very large channels and jitter in the speed readout.

1.0.0 2026-07-12

  • First public release: menu bar app, download queue, playlist support, in-place engine updates.
  • Sparkle appcast and the automated release workflow.
