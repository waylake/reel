링크를 복사하고,
⌘V만 누르세요

Reel은 YouTube를 비롯한 1,800개 사이트에서 받아오는 네이티브 macOS 다운로더입니다. yt-dlp와 ffmpeg가 맥 안에서 돌아갑니다. Electron도, 계정도, 텔레메트리도 없습니다.

01 / 사용법

세 단계, 단축키 하나.

주소를 붙여넣는 입력창도, 포맷을 고르는 대화상자도 없습니다. 이미 복사한 링크에서 시작합니다.

01⌘C

링크를 복사합니다

영상이나 오디오 페이지라면 무엇이든: YouTube, Vimeo, Twitch, TikTok, SoundCloud, 그리고 yt-dlp가 아는 나머지 1,800개 사이트.

02⌘V

Reel에서 붙여넣습니다

Reel은 메뉴 막대에 있습니다. 클립보드를 로컬에서 읽어 링크를 찾아 팝오버에 보여주고, ⌘V를 누르면 큐에 들어갑니다. 링크나 .txt 목록을 창에 끌어다 놓아도 됩니다.

03~/Movies/Reel

프리셋은 한 번만

최고 화질 MP4, 호환성을 위한 1080p H.264, MP3, M4A, 또는 원본 그대로. 바꾸기 전까지 모든 다운로드에 같은 설정이 쓰입니다. 파일은 지정한 폴더에 저장됩니다.

02 / 기능

엔진은 크고, 앱은 작게.

추출은 Reel이 하지 않습니다. 그 일은 yt-dlp가 하고, ffmpeg가 합치고 변환합니다. Reel은 네이티브인 부분만 맡습니다. 큐, 클립보드, 카드, 업데이트 경로.

클립보드
Reel은 클립보드를 로컬에서만 읽어 미디어 링크를 찾습니다. 찾은 링크는 메뉴 막대에 뜨고, 어디로도 전송되지 않습니다. 설정에서 감지를 끌 수 있습니다.
프리셋
최고 화질 MP4, 호환성을 위한 1080p H.264, MP3, M4A, 또는 재인코딩 없는 원본 파일.
재생목록
재생목록이나 채널 전체를 큐에 넣습니다. 항목 수 제한이 있어 900개짜리 채널이 디스크를 채우는 일은 없습니다.
파일
자동 생성 자막을 포함한 자막, 챕터, 메타데이터, 썸네일을 파일에 넣습니다. SponsorBlock으로 광고 구간을 건너뜁니다.
엔진
yt-dlp와 ffmpeg가 앱에 포함되어 있습니다. 사이트가 바뀌면 엔진만 제자리에서 업데이트합니다. 앱을 다시 켤 필요도, 터미널을 열 필요도 없습니다. 일시적인 YouTube 오류는 백오프로 재시도합니다.
로그인
멤버십이나 연령 제한 영상은 Safari, Chrome, Firefox의 쿠키를 넘겨서 받습니다. 쿠키는 맥을 떠나지 않습니다.
큐
동시에 최대 6개. 언제 꺼도 되고, 끝나지 않은 항목은 다음 실행에서 이어집니다.
03 / 화면

메뉴 막대와 창, 그게 전부.

지금 무슨 일이 일어나는지 보는 팝오버, 큐를 훑어보고 싶을 때 여는 창. 두 개면 충분합니다.

인터페이스는 아직 한국어입니다. 영어를 비롯한 다른 언어를 준비하고 있습니다.

04 / 한계

Reel이 하지 않는 것

모든 걸 된다고 말하는 다운로더는 보통 무언가를 숨기고 있습니다. 솔직하게 적습니다.

  • 계정이 없습니다. 가입도, 로그인도, 동기화도 없습니다.
  • 텔레메트리가 없습니다. 분석도, 크래시 리포트도, 광고도 없습니다. 앱이 스스로 하는 통신은 업데이트 확인뿐입니다.
  • DRM을 우회하지 않습니다. 서비스가 스트림을 암호화했다면 Reel은 받지 못합니다. 이건 열쇠가 아니라 다운로더입니다.
  • 브라우저 확장이 없습니다. 대신 아무 브라우저에서나 복사하면 됩니다. 그게 인터페이스 전부입니다.
  • 숫자를 만들지 않습니다. “1,800개 사이트”는 yt-dlp의 추출기 목록이지 마케팅 수치가 아닙니다. 그중 일부는 어느 날이든 깨져 있을 수 있습니다.

추출은 모두 yt-dlp의 일이고 Unlicense입니다. Reel은 그 위의 얇은 네이티브 프런트엔드입니다.

05 / 설치

1분이면 끝납니다.

macOS 14 Sonoma 이상, Apple silicon 또는 Intel. yt-dlp와 ffmpeg가 앱에 들어 있어 따로 설치할 것은 없습니다.

zip을 내려받아 압축을 풀고 Reel.app을 응용 프로그램 폴더로 옮기면 됩니다.

Reel.app.zip 다운로드
안내 Reel은 아직 공증(notarization)을 받지 않았습니다. 첫 실행 때 macOS가 막으면 Reel.app을 오른쪽 클릭 → 열기를 한 번만 해주세요. 그다음부터는 정상 실행됩니다. Homebrew 방식은 이 과정이 필요 없습니다.

Homebrew로 설치하면 같은 앱을 받고 격리 속성 문제도 생기지 않습니다.

$ brew install --cask waylake/tap/reel
신뢰 Homebrew 6.0부터 서드파티 tap은 명시적 신뢰가 필요합니다. cask 전체 이름으로 설치하면 이 cask 하나만 신뢰합니다.

직접 빌드합니다. 번들 엔진 없이도 만들 수 있습니다.

$ brew install xcodegen yt-dlp ffmpeg
$ git clone https://github.com/waylake/reel.git
$ cd reel && xcodegen generate
$ open Reel.xcodeproj

기여는 환영합니다. 먼저 CONTRIBUTING.md를 읽어주세요.

필요 Xcode 16 이상, XcodeGen, Homebrew. 로컬 빌드에는 Apple 개발자 계정이 필요하지 않습니다.
06 / 질문

광고 없는 답변.

아래 내용은 정확한 오류 메시지와 함께 문서에 정리되어 있습니다.

무료인가요?

네. MIT 라이선스이고 유료 티어도, 광고도, 업셀도 없습니다. 소스는 GitHub에 있습니다.

403이 뜨거나 “page needs to be reloaded” 오류가 납니다.

YouTube 쪽이 바뀐 것입니다. 설정 → 고급 → yt-dlp → 업데이트를 누르세요. 앱을 다시 켜지 않아도 바로 적용됩니다.

Reel은 일시적 오류를 백오프로 재시도하고 실패 시 yt-dlp를 자동 업데이트하지만, 수동 업데이트가 가장 빠릅니다.

macOS가 “확인되지 않은 개발자”라며 앱을 열지 않습니다.

Reel은 ad-hoc 서명만 되어 있고 Apple 공증은 받지 않았습니다. 응용 프로그램 폴더의 Reel.app을 오른쪽 클릭해 열기를 한 번 선택하세요. 아니면 Homebrew로 설치하면 격리 문제가 아예 생기지 않습니다.

제 정보를 어디로 보내나요?

아무 데도 보내지 않습니다. 분석도, 크래시 리포트도, 자체 서버도 없습니다. 클립보드는 링크를 찾기 위해 로컬에서만 읽습니다. 브라우저 쿠키를 켜면 다운로드하는 사이트로만 전달됩니다. 앱의 통신은 업데이트 확인과 다운로드 자체뿐입니다.

4K도 받을 수 있나요?

원본이 제공한다면 가능합니다. 최고 화질 MP4 프리셋은 사용 가능한 최고 화질의 영상과 오디오를 받아 ffmpeg로 합칩니다. VP9나 AV1을 못 읽는 편집기와 플레이어를 위해 1080p H.264 프리셋도 있습니다.

다운로드가 합법인가요?

콘텐츠와 거주 지역에 따라 다릅니다. 본인이 소유했거나, 허용된 라이선스로 제공되거나, 현지 법이 허용하는 것만 받으세요. 각 사이트의 약관을 존중해야 합니다. Reel은 DRM을 우회하지 않고 미디어를 호스팅하거나 배포하지 않습니다.

파일은 어디에 저장되나요?

기본값은 ~/Movies/Reel입니다. 설정 → 일반에서 바꿀 수 있습니다. 큐는 ~/Library/Application Support/Reel/queue.json에 있습니다.

주소를 입력창에 붙여넣지 마세요.

링크를 복사하고 ⌘V. 그게 전부입니다.
